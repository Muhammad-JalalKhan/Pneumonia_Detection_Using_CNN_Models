# 📄 PDF Report Generation - Installation & Usage Guide

## 🚀 Quick Install (3 Steps)

### Step 1: Install ReportLab

```powershell
# Activate your virtual environment first
.venv\Scripts\activate

# Install ReportLab (PDF library)
pip install reportlab
```

### Step 2: Replace Your app.py

Download `app_with_pdf.py` and either:
- **Option A:** Replace your current `app.py` with it
- **Option B:** Rename it to `app.py`

### Step 3: Run Dashboard

```powershell
streamlit run app.py
```

That's it! Your PDF download button should now work.

## 🔧 Troubleshooting PDF Generation

### Error: "No module named 'reportlab'"

**Fix:**
```powershell
pip install reportlab
```

---

### Error: "Cannot import SimpleDocTemplate"

**Fix:**
```powershell
pip uninstall reportlab
pip install reportlab==4.0.5
```

---

### PDF is blank or images missing

**Cause:** Image conversion issue

**Fix:** The code handles this gracefully - PDF will generate without images if embedding fails. Check that PIL/Pillow is installed:

```powershell
pip install --upgrade Pillow
```

---

### PDF download button not appearing

**Check:**
1. ReportLab is installed: `pip show reportlab`
2. No errors in terminal when running Streamlit
3. Function `generate_pdf_report()` is defined before use

Find this line in the code:

```python
title = Paragraph("🫁 PNEUMONIA AI DIAGNOSTIC REPORT", title_style)
```

### Add Your Hospital Logo

1. Add logo file to project folder (e.g., `logo.png`)

2. Add this code after the title:

```python
logo = RLImage('logo.png', width=1.5*inch, height=1.5*inch)
elements.append(logo)
elements.append(Spacer(1, 0.2*inch))
```

## 📏 PDF Specifications

- **Page Size:** US Letter (8.5" × 11")
- **Margins:** 0.75" all sides
- **Font:** Helvetica (standard PDF font)
- **File Size:** Typically 200-500 KB
- **Format:** PDF 1.4 (compatible with all readers)
- **Images:** Embedded PNG format

## 🔒 HIPAA Compliance Considerations

If using in a clinical setting:

### ✅ DO:
- Store PDFs in encrypted storage
- Use secure file transfer (HTTPS)
- Include patient consent
- Maintain audit logs
- Use anonymized patient IDs

### ❌ DON'T:
- Send via unencrypted email
- Include patient names without consent
- Store on public cloud without BAA
- Share outside authorized personnel

## 🆚 PDF vs Text vs CSV - When to Use What?

| Format | Best For | Advantages |
|--------|----------|------------|
| **PDF** | Medical records, formal reports | Professional, images included, non-editable |
| **CSV** | Data analysis, spreadsheets | Easy to analyze, import to Excel |
| **TXT** | Quick reference, simple viewing | Small size, universal compatibility |

**Recommendation:** Provide all three formats for maximum flexibility!

3. Test with simple code:
   ```python
   from reportlab.pdfgen import canvas
   c = canvas.Canvas("test.pdf")
   c.drawString(100, 750, "Hello World")
   c.save()
   ```
4. If test works, issue is in image embedding

## ✨ Advanced Features (Optional)

### Add Watermark

```python
# Add to PDF generation code:
from reportlab.pdfgen import canvas

def add_watermark(canvas, doc):
    canvas.saveState()
    canvas.setFont('Helvetica', 50)
    canvas.setFillColorRGB(0.9, 0.9, 0.9)
    canvas.drawString(100, 400, "DRAFT")
    canvas.restoreState()

# Use when building:
doc.build(elements, onFirstPage=add_watermark)
```

### Add Page Numbers

```python
def add_page_number(canvas, doc):
    page_num = canvas.getPageNumber()
    text = f"Page {page_num}"
    canvas.drawRightString(200*mm, 15*mm, text)

doc.build(elements, onFirstPage=add_page_number, onLaterPages=add_page_number)
```
